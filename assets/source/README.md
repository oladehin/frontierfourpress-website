Put designer files here, then run `python3 build.py`.

- Final cover: `escape-velocity-cover.jpg` (any size; the build makes a 1400 px web copy)
- Stack logo: `frontier-four-press-stack.svg` (white or single-colour on transparent works best on the coral footer)
- Fonts (optional): `fonts/*.woff2`, then list them in `site.config.json` > fonts.files

If you use different file names, change the paths in `site.config.json`.
